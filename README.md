# The Saffron Table - Restaurant Website
A responsive, single-page website for a fictional restaurant in Pune, India.
Built as my Web Development CA Project 1 using only HTML5 and CSS3.

## Description
The Saffron Table is a welcoming restaurant landing page with clear
information, appealing food imagery, a dark/light theme and a layout that
works on phones, tablets and desktops.

## Features

### Required
- Sticky header with smooth-scrolling navigation links
- Hero section with headline, call-to-action button and `@keyframes` entrance animation
- About section with a two-column text and image layout
- 8 menu cards (image, name, description, price) in a responsive CSS Grid
- Specials and offers section with 3 highlighted deal cards
- 3 customer testimonial cards with star ratings
- Footer with opening hours, address, phone, email and copyright
- Fully responsive using Flexbox, Grid and `@media` queries

### Optional enhancements
- Dark/light theme toggle (CSS-only, using a hidden checkbox and `:checked`)
- Card hover effects, button transitions and animated nav underlines
- Subtle keyframe animations in the hero section (slide-in, fade-in, floating image)
- Menu category bar linking to Starters, Mains, Desserts and Beverages
- Featured signature dish section
- Photo gallery with hover zoom
- Customer testimonials
- Respects the "reduce motion" accessibility setting

## Technologies Used
- HTML5 (semantic tags: header, nav, main, section, article, figure, footer)
- CSS3 (variables, Flexbox, Grid, transitions, keyframe animations, media queries)
- Google Fonts (Playfair Display, Poppins)
- Unsplash (placeholder food images)
